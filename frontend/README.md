# IPO Hub Frontend

## Overview
IPO Hub is a web application designed to simplify the management of IPO applications across multiple broker accounts. This frontend serves as the user interface for interacting with the backend services.

## Project Structure
- **index.html**: The page served by FastAPI.
- **styles/**: Contains CSS files for styling the application.
- **scripts/**: Contains JavaScript files for client-side functionality.

## Setup Instructions
1. Start the backend from the project root or `backend/` directory.
2. Open `http://127.0.0.1:8000` in a browser.

3. **Development**
   - Modify `index.html` to change the structure of the application.
   - Update styles in `styles/app.css` to customize the appearance.
   - Add or modify JavaScript functionality in `scripts/app.js`.

## Usage
- The application allows users to view and manage IPO applications.
- Users can interact with the backend API to submit applications and track their status.
